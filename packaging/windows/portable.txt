easyPDF portable mode

While this file sits next to easypdf.exe, easyPDF keeps its settings, log files, crash-recovery
autosaves and new digital IDs in the easyPDFData folder beside it, and writes nothing to
%APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move easyPDF with its settings.

Delete this file to use the normal per-user folders (%APPDATA%\easyPDF and
%LOCALAPPDATA%\easyPDF) instead. If easyPDFData can't be written (for example on a read-only
drive), easyPDF says so and uses the per-user folders instead.
