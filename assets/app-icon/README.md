# easyPDF app icon

Every icon in this directory is derived without visual changes from the official easyPDF mark in
`assets/easyPDF-icona.svg` and `assets/easyPDF-icona.png`.

The mark is owned by Twinba Srl and covered by
[`assets/LICENSE-easyPDF-brand.txt`](../LICENSE-easyPDF-brand.txt). It must be used unmodified and
only for easyPDF.

## Files

| File | Use |
|---|---|
| `easypdf.svg` | Master vector used by packaging and documentation |
| `easypdf-small.svg` | Vector alias for compact placements |
| `easypdf-1024.png` | macOS/Dock source at 1024 px |
| `easypdf.icns` | macOS icon containing 16–1024 px representations |
| `easypdf.ico` | Windows multi-resolution icon containing 16–256 px representations |
| `easypdf-document.svg` / `.ico` | easyPDF mark used for the associated PDF file type |
| `hicolor/<n>x<n>/apps/it.twinba.easypdf.png` | Linux icons at 16, 24, 32, 48, 64, 128, 256 and 512 px |
| `hicolor/scalable/apps/it.twinba.easypdf.svg` | Linux scalable icon |

The desktop app loads these files from `apps/easypdf`; Linux uses the application id
`it.twinba.easypdf`.
